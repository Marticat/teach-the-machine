TEACH THE MACHINE - GEMINI EDITION

1. Extract the entire ZIP into a folder.
2. Run START.cmd (Node.js 20 or newer is required).
3. Paste your Gemini API key into the prompt, then press Enter.
   The key is hidden and is not saved to a file or sent to the browser.
4. Open http://127.0.0.1:4173 in your browser.
5. Choose an available model, explain the topic and submit.
6. Keep the terminal open. Ctrl+C stops the server and discards the key.

The key is sent only to Google's Gemini API in the authentication header.
Your submitted lesson conversation is sent to Google. Google account quotas,
data policies and any configured billing apply. The app does not log chats.
Model availability is loaded from your account. A listed model can still be
restricted or require a quota; choose a different one if Google rejects it.
No automatic retry is performed for failed generation requests.

Milo simulates learning; the underlying model is not retrained.
Notebook observations use simple phrase matches; transfer tests are prepared.
Live replies are generated by Gemini and may contain errors.

Official API documentation:
https://ai.google.dev/api/generate-content
https://ai.google.dev/api/models
